# Issue: イベント一覧の「もっと見る」追加読み込みの実装

`/events` ページの表示件数を調整し、ページ遷移なしで追加のイベントを読み込める「もっと見る」ボタンを実装する。

## 背景
現在は1ページ20件の単純なページネーション（ページ遷移を伴う）となっている。ユーザー体験の向上、特にモバイル端末での閲覧性を高めるため、現在のリストを保持したまま追加で読み込む方式に変更する。

## 要件
- 初期表示件数を **12件** に変更する。
- 13件目以降がある場合、「もっと見る（Load More）」ボタンをリスト下部に表示する。
- 「もっと見る」ボタン押下時、ページをリロードせずに次の12件を追加取得し、リストの末尾に結合して表示する。
- 全てのイベントを読み込み終わった場合、ボタンを非表示にする。
- 検索フィルター（エリア、路線）が変更された場合は、リストをリセットして最初から読み直す。

## 実装方針
1. **Server Action の作成**: クライアントから追加データを取得するための `fetchPublicEventsAction` を `apps/web/src/app/[locale]/events/actions.ts` (新規作成) に定義する。
2. **Client Component への分離**: 現在の `EventsPage` 内のリスト表示部分と「もっと見る」ロジックを Client Component (`EventsList.tsx`) として切り出す。
3. **ローディング表示**: 追加取得中にスケルトンまたはスピナーを表示し、連続クリックを防止する。
4. **i18n**: 「もっと見る」ボタンのラベルを `ja.json` / `en.json` に追加する。

- [x] 「もっと見る」ボタンでデータが追加され、既存のリストが消えないこと。
- [x] 検索フィルター変更時に正しくリセットされること。
- [x] モバイル・デスクトップ両方でレイアウトが崩れないこと。
