# Issue 131: UI/UX Refinement for Event Search & Edit

## 概要
イベント検索ページおよびイベント編集画面の UI/UX を改善し、視認性と操作性を向上させます。また、最寄り駅情報の管理を会場（組織）に紐づける形に修正します。

## 変更内容

### 1. データベーススキーマの更新
- `organizations` テーブルに `nearest_station` (text) カラムを追加します。
- `events` テーブルの `nearest_station` は、基本的には会場の情報から取得するようにします。

### 2. 共通 UI コンポーネントの改善
- `apps/web/src/components/ui/select.tsx` の改善：
    - ブラウザネイティブな外観を脱却し、より視認性の高いカスタムスタイルを適用します。
    - クリックしやすいよう、高さ（height）とパディングを調整します。
- `Input` コンポーネントのサイズ感も合わせ、フォーム全体での操作性を統一します。

### 3. イベント検索ページの改善 (`/events`)
- **路線の非表示**: 検索条件から「路線」フィルタを一旦削除（または隠す）します。
- **都道府県セレクトボックス**: 新しい `Select` コンポーネントを適用し、操作性を向上させます。

### 4. イベント編集画面の改善 (`/dashboard/event/[id]/edit`)
- **最寄り駅の連動**: 
    - 「最寄り駅」を自由入力の `Input` から、選択した会場に紐づく情報を表示する形に変更します。
    - 会場選択（Select）時に、その会場の最寄り駅情報を表示し、イベント情報として保存されるようにします。
- **UI コンポーネント**: セレクトボックスや日時選択（DateTimePicker）の UI を改善します。

### 5. その他
- 全体的なフォーム要素の余白やフォーカス状態の視認性を改善します。
