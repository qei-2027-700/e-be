# i18n — 日本語・英語対応

## 完了条件

- Web・Mobile ともにUI文字列が翻訳キー経由で表示される
- `/ja/` と `/en/` の URL でそれぞれの言語が表示される
- 新規文字列追加時に `ja.json` と `en.json` の両方が更新される

---

## Web (Next.js): next-intl

### インストール

```bash
pnpm --filter web add next-intl
```

### ディレクトリ構成

```
apps/web/
├── messages/
│   ├── ja.json        # 日本語
│   └── en.json        # 英語
├── src/
│   ├── i18n/
│   │   ├── routing.ts # ロケール定義
│   │   └── request.ts # リクエストごとのロケール取得
│   └── app/
│       └── [locale]/  # ← 全ルートをこの下に移動
│           ├── layout.tsx
│           └── page.tsx
```

### routing.ts

```ts
import { defineRouting } from 'next-intl/routing'

export const routing = defineRouting({
  locales: ['ja', 'en'],
  defaultLocale: 'ja',
})
```

### messages/ja.json

```json
{
  "home": {
    "hero": {
      "tagline": "「良いイベント」を増やす。",
      "description": "店舗と主催者をつなぐ、イベントバー運営・分析プラットフォーム。",
      "cta_search": "イベントを探す",
      "cta_request": "開催リクエスト"
    }
  }
}
```

### messages/en.json

```json
{
  "home": {
    "hero": {
      "tagline": "Creating more great events.",
      "description": "The event bar management platform connecting venues and organizers.",
      "cta_search": "Find Events",
      "cta_request": "Request an Event"
    }
  }
}
```

### コンポーネントでの使用

```tsx
import { useTranslations } from 'next-intl'

export default function HomePage() {
  const t = useTranslations('home.hero')
  return <h1>{t('tagline')}</h1>
}
```

### proxy.ts（言語ルーティング）

```ts
import createMiddleware from 'next-intl/middleware'
import { routing } from './i18n/routing'

export default createMiddleware(routing)

export const config = {
  matcher: ['/', '/(ja|en)/:path*'],
}
```

## Mobile (Expo): i18next

### インストール

```bash
pnpm --filter mobile add i18next react-i18next
```

### 構成

```
apps/mobile/
└── src/
    └── i18n/
        ├── index.ts       # i18next 初期化
        ├── ja.json
        └── en.json
```

### 初期化

```ts
// src/i18n/index.ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import ja from './ja.json'
import en from './en.json'

i18n.use(initReactI18next).init({
  lng: 'ja',
  fallbackLng: 'ja',
  resources: { ja: { translation: ja }, en: { translation: en } },
  interpolation: { escapeValue: false },
})

export default i18n
```

---

## 実装ステップ

1. `next-intl` インストール・`messages/` 作成
2. `src/app/[locale]/` にルートを移動
3. `routing.ts` / `request.ts` / `proxy.ts` を設定
4. 既存のハードコード文字列を翻訳キーに置き換え
5. Expo 側に `i18next` を導入・同様に翻訳キー化
6. 言語切り替えUIをヘッダーに追加
