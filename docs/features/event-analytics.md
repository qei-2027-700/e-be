# イベント分析（Premium）

## 概要

事業者が自店舗のイベント実績を分析できる機能。Premium プランのみ利用可能。

## ユーザーストーリー

- 事業者として、どのイベントが人気だったか・売上はどうだったかを把握したい

## 表示項目（案）

| 指標 | 説明 |
|------|------|
| 参加者数 | イベントごとの参加人数・定員充足率 |
| リピート率 | 複数回参加しているユーザーの割合 |
| 人気イベンター | 参加者数が多いイベンターのランキング |
| 月別推移 | 参加者数・イベント開催数の月次グラフ |

## プラン制限

- `canUseFeature(plan, 'analytics')` で判定する
- Free プランのユーザーには「Premium にアップグレード」の誘導 UI を表示する

## CSV エクスポート・AI 分析エクスポート

- 分析データを CSV でダウンロードできる（Premium）
- AI 分析エクスポート: 分析サマリーをテキスト形式で出力し、クリップボードにコピーまたはファイルダウンロードできる（`ai_export` feature / Premium）
