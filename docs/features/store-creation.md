# 店舗作成・プロフィール設定

## 概要

事業者が自店舗をプラットフォームに登録し、プロフィール情報・アクセス情報・イメージカラーを設定する。

## ユーザーストーリー

- 事業者として、自店舗をプラットフォームに登録して、イベンターや参加者に見つけてもらいたい

## ビジネスルール

- 店舗作成は `org:owner` 権限を持つユーザーが行う
- 1ユーザーが複数の店舗を持てる（Premium 機能）
- 店舗作成と同時に作成者が `org:owner` になる
- 店舗の slug はユニークで URL に使用される（例: `/bars/my-bar`）
- 公開設定があり、非公開の間は一般ユーザーから見えない

## 設定項目

| 項目 | 必須 | 制約 |
|------|------|------|
| 店舗名 | ✅ | 最大 50 文字 |
| slug（URL） | ✅ | 英数字・ハイフンのみ / 最大 50 文字 / 変更不可 |
| 説明 | 任意 | 最大 1,000 文字 |
| アイコン画像 | 任意 | jpg / png / webp / 最大 3MB |
| カバー画像 | 任意 | jpg / png / webp / 最大 5MB |
| イメージカラー | 任意 | プリセットパレットから選択（HEX で保存） |
| 住所 | ✅ | 最大 200 文字 |
| 最寄り駅・アクセス | 任意 | 最大 200 文字 |
| 電話番号 | 任意 | 電話番号形式 |
| Web サイト URL | 任意 | URL 形式 |
| SNS リンク（X / Instagram 等） | 任意 | URL 形式 / 各 1 件 |
| 営業時間 | 任意 | 曜日ごとに開始・終了時刻を設定 |
| 定休日 | 任意 | 曜日で設定 |

## イメージカラーの仕様

- フェーズ1: プリセットパレットから選択
- フェーズ2: カスタム HEX 入力も可能（スキーマ変更なし）
- 文字色は背景色から WCAG コントラスト比で自動判定（白 or 黒）
- 詳細: `docs/architecture/decisions.md` #9
