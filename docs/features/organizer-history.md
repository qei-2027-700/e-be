# 主催履歴・公開設定

## 概要

イベンターが過去に主催したイベントの履歴を管理し、外部への公開可否を設定する。

## ユーザーストーリー

- イベンターとして、自分の主催履歴を実績としてプロフィールに掲載したい
- イベンターとして、特定の主催履歴は非公開にしておきたい

## ビジネスルール

- 主催履歴は `completed` になったイベントのみ表示される
- デフォルトは公開。イベンターが個別に非公開に設定できる
- 非公開にしても自分のダッシュボードからは確認できる
- `cancelled` / `rejected` のイベントは主催履歴に表示しない（自分のダッシュボードのみ確認可）

## CSV エクスポート

- 主催履歴を CSV でダウンロードできる
- 出力項目: イベント名・開催日・バー名・参加者数・ステータス
