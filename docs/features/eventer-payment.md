# イベンターへの支払い履歴

## 概要

事業者がイベンター（主催者）への支払い記録を管理・確認する機能。

## ユーザーストーリー

- 事業者として、イベンターへの報酬支払いの履歴を記録・確認したい

- 記録のみ（手動入力）か、Stripe 等と連携した自動記録か
- 支払い金額の計算方法（参加者数に応じた報酬設定など）

## CSV エクスポート

- 支払い履歴を CSV でダウンロードできる
- 出力項目: イベンター名・イベント名・金額・支払い日・ステータス
- `org:owner` のみ実行可能

※ 支払いフローが決まるまで実装しない。
