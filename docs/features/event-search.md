# イベント一覧・検索

## 概要

未ログインを含む全ユーザーが開催予定のイベントを探せる。

## ユーザーストーリー

- ユーザーとして、今週末に行けるイベントをエリアやジャンルで探したい

## 検索・絞り込み項目

| 項目 | 説明 |
|------|------|
| キーワード | タイトル・説明文を全文検索 |
| 日付 | 開催日で絞り込み（カレンダー表示も可） |
| エリア | 店舗の所在地で絞り込み |
| タグ | イベントに付けられたタグで絞り込み |

## 表示対象

- `published` かつ `start_at` が未来のイベントのみ表示（`ongoing` も表示する）
- `cancelled` / `completed` / `draft` / `pending` / `rejected` は表示しない

## イベント詳細

| 項目 | 説明 |
|------|------|
| タイトル・説明 | イベントの概要 |
| 開催日時 | `start_at` / `end_at`（ユーザーのタイムゾーンで表示） |
| 開催場所 | バー名・住所・地図リンク |
| 主催者 | イベンターのプロフィールへのリンク（公開設定に準拠） |
| 定員・残席 | 定員が設定されている場合のみ表示 |
| 参加ボタン | ログイン済みユーザーのみ操作可 |
| 利用可能クーポン | 自分が所持しているこのイベント紐づきのクーポン |

## クリップボードコピー

- イベント詳細ページに「URL をコピー」ボタンを設置する
- コピー内容: イベントの公開 URL（SNS シェア・口コミ用途）
