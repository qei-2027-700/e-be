# イベント参加表明

## 概要

ユーザーがイベントへの参加を表明し、参加履歴を確認する。

## ユーザーストーリー

- ユーザーとして、気になるイベントに参加表明して、当日の案内を受け取りたい
- ユーザーとして、過去に参加したイベントを振り返りたい

## ビジネスルール

- 参加表明できるのは `published`（開始前）のイベントのみ
- 定員が設定されている場合、定員に達したら参加表明できない
- 参加キャンセルは開催中（`ongoing`）になる前まで可能
- イベントがキャンセルされた場合、参加者全員に通知が届く

## 参加履歴

- 参加表明済み・参加済み・キャンセル済みのイベントを一覧で確認できる

## 参加者リスト CSV エクスポート

- イベンター・事業者がイベントの参加者一覧を CSV でダウンロードできる
- 出力項目: 参加者名・参加表明日時・ステータス（参加済み / キャンセル済み）
- 個人情報を含むため、`org:owner` / `org:member` / イベント主催者のみ実行可能
