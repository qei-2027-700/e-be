# バー一覧・検索・詳細

## 概要

未ログインを含む全ユーザーが登録バーを探し、詳細・アクセス情報・開催予定イベントを確認できる。

## ユーザーストーリー

- ユーザーとして、近くのイベントバーを探してアクセス方法を確認したい

## 検索・絞り込み項目

| 項目 | 説明 |
|------|------|
| キーワード | 店舗名・説明文で検索 |
| エリア | 所在地で絞り込み |

## バー詳細ページ

| 項目 | 説明 |
|------|------|
| 店舗名・説明 | プロフィール情報 |
| イメージカラー | 背景・文字色に反映 |
| アイコン / カバー画像 | |
| 住所・アクセス | 最寄り駅・地図リンク |
| 電話番号・URL・SNS | 設定されている場合のみ表示 |
| 開催予定イベント | `published` かつ `start_at` が未来のイベント一覧 |
| Google Calendar に追加 | 店舗の予定を Google Calendar へエクスポート（TBD） |

## ビジネスルール

- 非公開に設定されている店舗は一覧・検索に表示されない
- 店舗 URL は `/bars/[slug]` の形式

## クリップボードコピー

- バー詳細ページに「URL をコピー」ボタンを設置する（シェア用）
- アクセス情報（住所）の横に「コピー」ボタンを設置する（地図アプリへの貼り付け用途）
