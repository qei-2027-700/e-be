# フードガイド（イベンター向け情報提供）

## 概要

イベンターがイベントでフードを提供する際の参考情報をプラットフォームが提供する。
一度作成したら更新頻度は低いため、MDX ファイルをリポジトリで管理して静的ページとして表示する。

## ユーザーストーリー

- イベンターとして、イベントでフードを出す際の価格設定やメニューの参考情報を知りたい

## コンテンツ構成（案）

| ページ | 内容 |
|--------|------|
| 価格設定の考え方 | 原価率の目安・利益計算の例・価格帯の参考 |
| おすすめメニュー | 軽食・おつまみ・ドリンク等のアイデア集 |
| スーパー別原材料リスト | 入手しやすい食材・コスパの良い原材料の紹介 |
| 食品衛生・アレルギー | アレルギー表示の注意点・衛生管理の基本 |
| 必要な機材リスト | 調理器具・容器・保温グッズなどの準備リスト |

## 実装方針

- コンテンツは `apps/web/content/guides/` 以下に MDX ファイルとして管理する
- 日英対応: `{slug}.ja.mdx` / `{slug}.en.mdx`
- Next.js で `/[locale]/guides/[slug]` として静的ページ（SSG）生成する
- 更新は MDX ファイルを編集して PR を出すだけ（CMS 不要）
- ナビゲーション: アプリ内のイベンター向けメニューやイベント作成画面からリンク

## ビジネスルール

- コンテンツは E-be 運営側が作成・管理する（ユーザー投稿ではない）
- 日英両方のファイルが揃っていない場合は日本語版にフォールバックする
- 特定のプランに限定しない（全ユーザーが閲覧可能）
