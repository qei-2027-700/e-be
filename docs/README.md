# E-be 機能一覧

イーベ（E-be）のすべての機能を、利用者の視点でまとめたインデックスです。
各機能の詳細仕様は `docs/features/` を参照してください。

---

## 事業者・店舗経営者

### 店舗管理

| 機能 | 説明 | 状態 |
|------|------|------|
| 店舗作成・プロフィール設定 | 店舗名・説明・写真・SNSリンクなどを登録する | 未着手 |
| アクセス情報設定 | 住所・最寄り駅・地図・駐車場情報を登録・表示する | 未着手 |
| 営業時間・休業日設定 | 通常の営業時間と定休日を設定する | 未着手 |
| 従業員管理（メンバー管理） | 従業員アカウントの追加・削除・権限管理 | 未着手 |
| オーナー権限移譲 | 店舗オーナー権限を別のメンバーへ移譲する | 未着手 |

### イベント管理

| 機能 | 説明 | 状態 |
|------|------|------|
| 自店舗カレンダー | 自店舗の予約状況・空き枠・利用不可枠をカレンダーで管理する | 未着手 |
| 利用不可枠設定 | 休業日・貸し切り・メンテナンス等の時間帯をブロックする | 未着手 |
| 公開リクエスト承認・却下 | イベンターからの開催申請を確認して承認または却下する | 未着手 |
| イベンター自動許可設定 | 特定のイベンターへ申請なしで公開できる許可を付与・取り消しする | 未着手 |
| イベントキャンセル | 公開済み・開催中のイベントをキャンセルする（開催中はオーナーのみ） | 未着手 |

### 集客・マーケティング

| 機能 | 説明 | 状態 |
|------|------|------|
| クーポン発行 | 参加者向けのクーポンを作成・配布・管理する | 未着手 |
| イベント分析 | 参加者数・売上・リピート率などの統計を閲覧する（Premium） | 未着手 |

### 決済・精算

| 機能 | 説明 | 状態 |
|------|------|------|
| イベンターへの支払い履歴 | 主催したイベンターへの支払い記録を管理する | 未着手 |

## ユーザー・イベンター

### イベント主催

| 機能 | 説明 | 状態 |
|------|------|------|
| イベント作成・下書き保存 | タイトル・説明・定員などを入力して下書きとして保存する | 未着手 |
| バーカレンダーで日時選択 | 開催したいバーのカレンダーを確認して空き枠を選ぶ | 未着手 |
| 公開リクエスト送信 | 日時が決まったバーに開催申請を送る | 未着手 |
| 即時公開（許可済みの場合） | 許可済みのバーであれば申請なしで即公開する | 未着手 |
| 主催履歴・公開設定 | 過去の主催イベントを一覧で見る。外部への公開可否を設定する | 未着手 |

### イベント参加

| 機能 | 説明 | 状態 |
|------|------|------|
| イベント参加表明 | イベントへの参加を表明する | 未着手 |
| 参加キャンセル | 参加を取り消す | 未着手 |
| 参加履歴 | 過去に参加したイベントを一覧で見る | 未着手 |
| クーポン取得・使用 | イベントで使えるクーポンを取得・提示する | 未着手 |

### プロフィール

| 機能 | 説明 | 状態 |
|------|------|------|
| プロフィール設定 | 名前・アイコン・自己紹介などを設定する | 未着手 |
| お気に入り店舗登録 | よく行くバーをお気に入りに追加する | 未着手 |

## 通知

| 機能 | タイミング | 対象 | 状態 |
|------|-----------|------|------|
| 申請受信通知 | イベンターが公開リクエストを送ったとき | バー owner | 未着手 |
| 承認・却下通知 | バーがリクエストを承認・却下したとき | イベンター | 未着手 |
| 参加表明通知 | ユーザーが参加表明したとき | イベンター | 未着手 |
| キャンセル通知 | イベントがキャンセルされたとき | 参加者全員 | 未着手 |
| 開催リマインダー | イベント前日または数時間前 | 参加者全員 | 未着手 |

## カレンダー連携

アプリ独自のカレンダーを持ちつつ、Google Calendar との連携を段階的に提供する。

| 機能 | 説明 | 状態 |
|------|------|------|
| イベントを Google Calendar に追加 | 参加・主催するイベントをワンタップで Google Calendar に追加する（`.ics` / Google Calendar URL） | 未着手 |
| バーカレンダーの Google Calendar 同期 | バーオーナーが Google Calendar で管理している予定をアプリに取り込む | TBD |

> バーの空き枠確認・重複チェックはアプリ独自カレンダーで完結させる。
> Google Calendar はあくまで「個人カレンダーへのエクスポート」として連携する。
